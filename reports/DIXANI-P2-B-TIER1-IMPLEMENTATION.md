### 3.3 "Net variance" vs "gross variance" — Task 1 body addition (§6.2 G1)

Inserted **one paragraph** immediately after the existing `BASIC FORMULA` box and **before** the
existing "A variance should not be treated as an automatic instruction…" paragraph. This is the
exact placement §6.2 specified: *"under the existing `What is an inventory variance?` H2, defining
net variance (variances summed with sign — shortages offset by overages) and distinguishing it
from gross/absolute variance."*

**Added text (verbatim):**
```
Net variance is the total of every item variance added together with its sign, so shortages
reduce the total and overages offset it. If one SKU is short 35 units and another is over by
20 units, the net variance is −15 units. Net variance shows the overall balance of the count,
but it can hide offsetting errors: a large shortage and a large overage can cancel out and still
leave the net variance close to zero. Gross variance (also called absolute variance) adds the
size of each variance without regard to sign, so the same two items give a gross variance of
55 units. Use net variance to reconcile the total against the system, and gross variance to
judge how much error the count actually found.
```

**Factual accuracy checks performed:**

| Claim | Verification |
|---|---|
| `−35 + 20 = −15` | ✅ Computed in Node: `net = -15` |
| `abs(−35) + abs(20) = 55` | ✅ Computed in Node: `gross = 55` |
| "shortages reduce the total and overages offset it" | ✅ Correct sign convention; matches the page's own existing line *"A negative variance means the physical quantity is lower than the system quantity."* |
| "Gross variance (also called absolute variance)" | ✅ Standard inventory-control terminology; `absolute variance` is the conventional synonym |
| Consistent with the page's worked example | ✅ Uses 35 units — the page's own example shortage — so the paragraph reads as an extension of existing content, not a new dataset |

**This was applied because the brief's TASK 1 explicitly requests it** ("Add a concise, accurate
explanation of net inventory variance if genuinely relevant to the page" + "Distinguish net
variance from gross/absolute variance where useful"). It would otherwise be Tier 2 (§8 #5).
**Relevance is genuine, not keyword-driven:** the page's H2 is literally *"What is an inventory
variance?"*, and a summation/sign distinction is a core part of answering that question. No formula
was added or altered; the existing formula box is byte-identical.

**Title and H1 preserved — verified programmatically (§5.1 and §5.3 below).**

## 8. Expected Measurement Limitations

**The changes cannot be validated from a 42-day, 22-click sample.** Stated plainly so that no
future reader mistakes noise for signal:

1. **Statistical power is effectively zero.** The analysis §2.3 notes the gauge holds *1 click /
   276 impressions* and *2 clicks / 246 impressions* — statistically indistinguishable. A CTR move
   of several percentage points would be required before any difference is distinguishable from
   chance at this volume.
2. **GSC's snippet-rewriting confounds the test.** Google may substitute its own snippet text. If it
   does, the measured CTR reflects Google's copy, not this change. There is no way to separate the
   two from GSC alone.
3. **Intent-mismatch impressions cannot be fixed by copy.** The analysis §1 finding #4 notes a large
   share of impressions come from queries the page is not the best intent match for
   (`inventory variance report template` @ 23.77, `net variance` @ 9.32, `count sheet template` @ 22,
   `abc analysis example` @ 76.33). **Snippet copy cannot convert a query whose intent the page does
   not serve.** Some of the low CTR will persist regardless of this change.
4. **Position volatility is large.** Daily average position ranged **12.8 → 44.5** across the
   window. Position swings alone will move CTR more than a description edit can.
5. **No rich-result feedback yet.** `Search appearance.csv` was empty (§2.3), so P2-A's schema
   cannot be measured either. There is no controlled way to isolate P2-B's snippet effect from
   P2-A's structural effect at this stage.
6. **Geography confound.** US traffic = 1,435 impressions, 0 clicks, position 43.05; clicks cluster
   in India, Malaysia, Qatar, Kenya, Sri Lanka and Mexico. A snippet tuned to one market's phrasing
   may read differently in the markets that actually click.
7. **Therefore:** treat any observed CTR movement as **directional and unproven** until the window
   is long enough and the impression base large enough to support a comparison. **Recommended
   observation window: 28 days minimum** (§8 "Deploy 1"), preferably with page-filtered query data
   from the GSC UI to establish true query→page attribution before drawing conclusions.
